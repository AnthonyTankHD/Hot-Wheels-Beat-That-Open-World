# Contributing

This is an open-source project (MIT). Contributions are welcome — cars,
tracks, city parts, skins, bug fixes, docs.

- Fork the repo, make your change, open a pull request.
- Keep the Hot Wheels look and feel: bright, fast, toy-car scale.
- Don't redistribute the original Beat That game files themselves;
  this repo holds our own code and assets, not the game's archives.
- Mods go in `mods/` — see the mod manager docs when they land.
